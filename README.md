## Selected engineering work

### [DriftPin](https://github.com/nikhiltulsani1/DriftPin) — requirements-to-test generation

A Python system that turns product requirements into traceable test cases and records ambiguities rather than inventing assumptions.

- **Design:** requirement registry, structured generation, review and adversarial specification checks.
- **Documented evaluation:** in one nine-defect adversarial run, **5 issues were fully detected and 4 partially detected**.
- **Important distinction:** three-provider runs achieved 100% **structural** coverage. This does *not* establish 100% semantic recall or test effectiveness.
- **Known limitations:** precision and lifecycle-edge-case behavior remain documented.

[Source and setup](https://github.com/nikhiltulsani1/DriftPin) · [Evaluation methods and limitations](https://github.com/nikhiltulsani1/DriftPin/blob/main/EVALS.md)

### [Calibrated RAG](https://github.com/nikhiltulsani1/calibrated-rag) — retrieval and grounded answers

A research-document assistant using BM25 and dense retrieval, reciprocal-rank fusion, grounding checks, abstention logic and OpenTelemetry.

- **Design:** hybrid retrieval, RRF, retry logic and answer checks.
- **Documented evaluation:** mean RAGAS faithfulness **0.9753 on 26 scored questions out of 36 attempted**.
- **Important distinction:** two abstentions and eight failures were excluded from that mean. Evaluation reference answers were LLM-generated, not human-verified.

[Source and setup](https://github.com/nikhiltulsani1/calibrated-rag) · [Generation evaluation report](https://github.com/nikhiltulsani1/calibrated-rag/blob/main/evals/REPORT_generation_expansion.md) · [Abstention reports](https://github.com/nikhiltulsani1/calibrated-rag/tree/main/evals)
